Random Quote Generator

My extension is a button designed to copy the generated quote and the author of the quote. This feature allows users to easily share the quote on social media platforms or with friends. For my critique project, I can see myslef using a video API to show popular videos on the page. This seems like the simplest way to add an API to my critique project. If I have more time, I would like to explore filtering videos based on user preferences or trending topics.
